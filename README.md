# FakeGoogle
I den här uppgiften gjorde jag en fejkad version av Googles startsida med hjälp av HTML och CSS. Jag skapade en Google logga en sökruta knappar och en footers med länkar. Jag använde CSS för att ändra färger, storlek, bakgrund och placering så att sidan skulle likna den riktiga Google sidan så mycket som jag kunde. Det som gick bra var att jag lyckades få sidan att likna Google ganska mycket. Jag fick till den mörka bakgrunden och den vita loggan och sökrutan och knapparna. Jag lärde mig också hur man använder HTML taggar som div, input, button och footer. Det som var svårt var att få alla delar att hamna på rätt plats. Jag hade problem med att få footern längst ner på sidan och att få ikonerna vid sökrutan att visas korrekt. Jag fick även testa olika pixelstorlekar och avstånd i CSS flera gånger innan layouten såg bra ut. Genom uppgiften lärde jag mig mer om hur HTML används för att skapa innehåll och hur CSS används för att styla och placera innehållet på en webbsida.
